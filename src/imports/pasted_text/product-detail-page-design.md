Design a modern, premium, conversion-optimized Product Detail Page for a furniture rental platform.

The current page feels outdated, heavy, and lacks visual hierarchy. The redesign should feel comparable to modern ecommerce experiences such as Airbnb, Apple, IKEA, Wayfair, Rentomojo, and Furlenco.

The primary goal is to increase engagement, trust, and Add-to-Cart conversions.

Design Principles

Create a clean, premium, modern interface with:

Large whitespace
Soft shadows instead of heavy borders
Consistent spacing system
Rounded corners (16–20px)
Modern typography hierarchy
Minimal visual clutter
Mobile-first responsive design
Fast scanning experience
Accessibility-compliant contrast ratios

Use a neutral background with white cards and a sophisticated navy accent color.

The overall aesthetic should feel:

Premium
Trustworthy
Modern
Comfortable
Lifestyle-oriented
